# 一、并发基础

## 1.1 进程 vs 线程

进程是资源分配的最小单位，线程是 CPU 调度的最小单位。

核心差异如下：

| 维度 | 进程 | 线程 |
| --- | --- | --- |
| 内存 | 独立地址空间 | 共享堆，独立栈 |
| 切换开销 | 大（TLB 刷新） | 小 |

## 1.2 为什么用多线程

- 利用多核 CPU 并行计算
- 避免 IO 阻塞主线程
- 提升吞吐量

# 二、锁机制

## 2.1 互斥锁

互斥锁在阻塞时会进入内核态等待，适合临界区较长的场景。

## 2.2 自旋锁

自旋锁不放弃 CPU，循环 CAS 尝试加锁。

```cpp
atomic<bool> flag{false};

void lock() {
    while (flag.exchange(true)) {}
}
```

## 2.3 死锁的四个必要条件

1. 互斥
2. 持有并等待
3. 不可剥夺
4. 循环等待

# 三、实践建议

> 一句话原则：锁的粒度要小，持有时间要短。
